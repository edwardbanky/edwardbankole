# Unit 1: What is Computing?

**Module:** Launch into Computing  
**Programme:** MSc Artificial Intelligence  
**University:** University of Essex Online

## Unit Overview

This unit introduces computing, its major disciplines,
and its role in modern business and technological innovation.

## Learning Outcomes

- Analyse computing challenges in business systems.
- Gather and synthesise information from multiple sources.
- Discuss legal, social, ethical and professional issues.

## Learning Activities

- Introduction to Computing lecturecast
- Unit 1 reading
- AI-powered assistants case study
- Python exercises using Think Python
- GitHub and GitHub Copilot setup
- Foundations of Computing seminar
- Collaborative Learning Discussion
