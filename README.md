# MSc Artificial Intelligence — Academic Portfolio.

Personal learning portfolio for Edward Bankole, MSc Artificial Intelligence student at the University of Essex.

## Publishing on GitHub Pages
1. Create a public GitHub repository (or use an existing portfolio repository).
2. Upload the **contents** of this folder to the repository root. `index.html` must be at the root, not inside another folder.
3. In GitHub, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Select your main branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

## Editing
- `index.html`: homepage and navigation tiles.
- `about.html`, `units.html`, `projects.html`, `research.html`: content pages.
- `assets/css/main.css`: styles.
- `images/`: supplied background and tile photographs.
- `template-reference/`: copies of the original HTML5 UP template files for reference.

## Important
- This version uses a self-contained replacement stylesheet because the original template CSS and JavaScript were not among the uploaded files.
- The supplied icon font files are deliberately **not redistributed**. The website does not need them.
- Keep the original HTML5 UP attribution and licence information.
- Check academic integrity and privacy requirements before publishing coursework or datasets.
